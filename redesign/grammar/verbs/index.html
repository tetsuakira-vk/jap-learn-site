The Three Verb Groups

動詞のグループ

Japanese verbs fall into three groups based on how they conjugate. Identifying the group is the first step to forming any conjugation correctly.

Quick identification

  • 〜る (E/I sound)→ Almost certainly Group 2 (ichidan): 食べる、見る、起きる
  • 〜う sound→ Group 1 (godan): 書く、飲む、話す、待つ、買う
  • する / くる→ Group 3 (irregular): する (to do), くる (to come)

Exceptions: Some verbs end in る but are Group 1 — 帰る (kaeru, to return), 走る (hashiru, to run), 知る (shiru, to know), 切る (kiru, to cut). These must be memorised individually.

Group 2 — Ichidan Verbs

一段動詞
G2
Ichidan (一段)
Drop る, add ending

Group 2 verbs all end in る, with the vowel before る being an e or i sound. To conjugate: drop the る, add the new ending. That's it — no stem changes.

Pattern: drop る + add ending

  • 食べるstem = 食べ → 食べます、食べて、食べた、食べない
  • 見るstem = 見 → 見ます、見て、見た、見ない
  • 起きるstem = 起き → 起きます、起きて、起きた、起きない

Group 1 — Godan Verbs

五段動詞
G1
Godan (五段)
Final kana changes across the five vowel rows

Group 1 verbs conjugate by changing the final kana across different vowel rows (あ/い/う/え/お). The pattern differs by the verb's ending consonant — the table below shows each ending type.

Stem changes by ending type

  • 〜く (書く)か行: か・き・く・け・こ → 書か/書き/書く/書け/書こ
  • 〜ぐ (泳ぐ)が行: が・ぎ・ぐ・げ・ご → 泳が/泳ぎ/泳ぐ/泳げ/泳ご
  • 〜す (話す)さ行: さ・し・す・せ・そ → 話さ/話し/話す/話せ/話そ
  • 〜つ (待つ)た行: た・ち・つ・て・と → 待た/待ち/待つ/待て/待と
  • 〜ぬ (死ぬ)な行: な・に・ぬ・ね・の → 死な/死に/死ぬ/死ね/死の
  • 〜ぶ (遊ぶ)ば行: ば・び・ぶ・べ・ぼ → 遊ば/遊び/遊ぶ/遊べ/遊ぼ
  • 〜む (飲む)ま行: ま・み・む・め・も → 飲ま/飲み/飲む/飲め/飲も
  • 〜る (帰る)ら行: ら・り・る・れ・ろ → 帰ら/帰り/帰る/帰れ/帰ろ
  • 〜う (買う)わ行: わ・い・う・え・お → 買わ/買い/買う/買え/買お

Irregular Verbs

不規則動詞

Only two fully irregular verbs in Japanese: する (to do) and くる (to come). These must be memorised — they follow no predictable pattern. Many compound verbs use する (勉強する、運動する、結婚する).

て-form rules for Group 1

The て-form of Group 1 verbs follows sound-change patterns (音便 onbin):

  • 〜く → いて (書く → 書いて) — exception: 行く → 行って
  • 〜ぐ → いで (泳ぐ → 泳いで)
  • 〜す → して (話す → 話して)
  • 〜つ・る・う → って (待つ → 待って、帰る → 帰って、買う → 買って)
  • 〜ぬ・ぶ・む → んで (死ぬ → 死んで、遊ぶ → 遊んで、飲む → 飲んで)
